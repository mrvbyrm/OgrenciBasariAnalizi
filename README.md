# OgrenciBasariAnalizi

[![Status](https://img.shields.io/badge/tür-veri%20madenciliği%20raporu-blue?style=flat-square)]()

Öğrenci başarısını etkileyen faktörleri veri madenciliği teknikleriyle analiz eden bir proje.

## Proje Hakkında

Bir anket çalışmasından toplanan verilerle öğrenci akademik başarısı incelenmiş; bulgular bir proje raporunda derlenmiştir. Bu repo kod değil, çalışmanın veri ve rapor dosyalarını içerir.

## İçerik

| Dosya | Açıklama |
|---|---|
| `Anket_Yanıtları.xlsx` | Ham anket verisi |
| `Veri Madenciliği Proje Raporu.docx` / `.pdf` | Proje raporu |
| `COLABLINK.txt` | Analizin yapıldığı Google Colab not defterinin bağlantısı |
